# ランディングページの作成と編集 {#create-and-edit-a-landing-page}

Adobe Campaignを利用すれば、オーディエンスに関する情報の取得、サービスへのサブスクリプションの提供、データの表示、データベースの拡張に使用できるオンラインフォームであるランディングページを構築できます。 ランディングページは、既存のプロファイルの取得や更新にも利用できます。
