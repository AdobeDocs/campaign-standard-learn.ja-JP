# 多言語メールまたはSMS配信の作成

Adobe Campaignを使用すると、多言語施策を送信する際の操作の複雑さを軽減できます。 メール配信とSMS配信はどちらも多言語として設定でき、プロファイルの好みの言語に基づいてメールやSMSを送信できます。

このビデオでは、メールニュースレターの例に基づいて、テンプレートに基づいて多言語配信を作成する方法を説明します。 動画で紹介されているアプローチは、電子メール配信とSMS配信の両方に適用されます。
